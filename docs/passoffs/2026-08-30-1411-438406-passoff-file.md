# 2026-08-30-1411-438406-passoff-file

## Summary

Added a secure, manual FantasyPros public v2 NFL ingestion flow and an append-safe historical player-points import. The workbook now creates current source tabs plus a `FantasyPros History` PPR summary across imported seasons. The complete public API question catalog and the completed contract plan are included. The implementation was checked against the official OpenAPI contract and independently reviewed twice.

The feature branch was reconstructed from `origin/main` after GitHub verified that the original local baseline and the remote default had no common commit. This branch preserves both source sets through ordinary commits and does not rewrite history.

## Files changed

- Modified `apps-script/code.gs` and `apps-script/code.test.js` to add header-authenticated FantasyPros fetching, source normalizers, a document-locked history import, and 72 automated tests.
- Modified `docs/README.md`, `docs/api.md`, `docs/architecture.md`, `docs/configuration.md`, `docs/data-model.md`, `docs/operations.md`, `docs/sources.md`, and `docs/testing.md` to document configuration, operation, data, and verification.
- Added `docs/fantasypros-question-catalog.md` and `docs/plans/2026-08-30-fantasypros-api-integration.md`.

## Key decisions

- Store the API key only in Apps Script Script Properties as `fantasyProsApiKey`, because source files, logs, and sheets must not contain credentials.
- Implement NFL only, because the workbook is NFL-specific while the reviewed provider contract covers several sports.
- Keep ingestion manual, because the public documentation does not state a refresh allowance or rate limit.
- Import historical NFL points for `STD`, `HALF`, and `PPR`, then summarize PPR performance in `FantasyPros History`.

## Risks and open questions

- A valid FantasyPros API key and its entitlement are required before the workbook can fetch live or historical data.
- Historical availability begins at 2012 according to the contract, but returned depth remains provider and entitlement dependent.
- Private league roster, matchup, transaction, waiver, and league-history questions require a league-host API or an import, not this public API.
