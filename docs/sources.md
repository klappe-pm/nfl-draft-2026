# sources

## authoritative-sources

Official draft results and prospect records use `https://www.nfl.com/draft/tracker/2026/prospects`. NFL franchise reference data is maintained in `_nfl_info`. The saved local official NFL page was parser-tested for 257 selections from Fernando Mendoza at No. 1 through Red Murdock at No. 257.

## limitations

The NFL tracker is the sole real-time ingestion source. `Team-Needs`, league managers, rules inputs, and notes are user-entered operational data. Charts and analysis update from workbook formulas, not external formula imports. Verification dates and source status belong in `Source Center`.
